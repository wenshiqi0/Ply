# RFC 0018：可信宿主的模型目录、视觉聊天与取消

> 状态：历史实现，协议入口已被 [RFC 0019](0019-acp-plugin.md) 取代 · 2026-11-02

Kite 需要接入 Linux Ply，并保留原生模型、思考、视觉、工具、审批和会话上下文。现有 CLI/MCP 仅调用任务，不能以缺失适配作为原生能力不足。

- agent 增加仅供可信宿主调用的模型目录与连续聊天导出；模型可见的 agent 工具不获得模型凭据选择或任意上下文恢复权限。
- 目录来自已加载原生模型接入和 pi-ai；MiMo 的当前型号继续由原生 mimo 插件维护。图像与思考选项按实际模型声明校验。
- 连续聊天复用现有 agent 执行、工具授权、报告校验及 context 恢复/导出，不另写模型循环。图像通过原生多模态消息传入；完整恢复快照只回传可信宿主私有存储。
- MCP 支持 notifications/cancelled，取消对应请求及其调用树；交互审批通过原有 approval 事件与宿主适配器回答，不自动批准。
- MCP 可显式选择原生审批模式，缺省行为不改变。

验证包括目录/图像/上下文与权限约束、MCP 取消和本地模型夹具；实际供应商检查使用明确授权的隔离会话。
