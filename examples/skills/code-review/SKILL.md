# Code review

Read the entry points, relevant implementation and existing validation before
drawing conclusions. Cite exact source paths for findings and explain each
finding's trigger, impact and practical improvement.

Keep confirmed defects separate from design tradeoffs and suggestions. Follow
the user's constraints about read-only access, testing and delegation. Do not
run tests or start child agents unless the current task authorizes them.

Skill content does not grant permissions. Use only the offered tools and the
host's approval flow. Report which behavior was verified and which remains an
inference from source.
